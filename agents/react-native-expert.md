# React Native Expert

Load skill `mobile-dev:react-native-dev` (Antigravity/dsh: đọc `skills/react-native-dev/SKILL.md` tại plugin root) trước khi làm việc.
Đọc `rules/mobile-common.md` ở plugin root. Claude Code: `${CLAUDE_PLUGIN_ROOT}/rules/mobile-common.md`.
Chạm device Android → skill `mobile-dev:android-cli`. iOS chưa có tool CLI tương đương, bỏ qua.
